# DCMA 电机与变频器监控展板

本项目提供电机与变频器采样数据的查看页面，从 MySQL 数据库只读查询设备记录，展示最新读数、近期趋势、分类参数以及历史故障与报警事件。

当前工作范围是**监控展板**。展板主要功能及相关联调已完成，代码和介绍文档已同步到个人仓库；目前采用本机启动方式，尚未部署为在线服务。Pi SDK 学习和完整工业 Agent 计划是后续独立工作。

## 页面功能

| 页面 | 功能 |
|---|---|
| 设备概览 | 当前设备、运行信息、按8组分类的29个完整参数、电机与变频器插图 |
| 实时数据 | 设定/实际转速与转矩对比、18项指标单项趋势、六个半圆仪表 |
| 运行指标 | 按运动、电气、功率、温度、负荷查看18项指标，点击进入对应趋势 |
| 故障与报警 | 当前代码、全历史事件、北京时间范围查询、汇总、代码分布和分页 |
| 采样明细 | 所选设备最近50、100或200条原始记录，保留完整数值精度 |
| 数据说明 | 数据来源、时间、单位、代码和图表显示规则 |

左侧选择“查看设备”后，六个页面同步展示这一台电机的数据。切页保留设备、来源和采样条数选择；最新值与近期采样每3秒检查一次，支持手动刷新。历史异常独立每30秒检查一次，也可以点击“查询异常”。

## 已有本机环境：怎样打开页面

如果本机已经配置过依赖和数据库，打开两个 PowerShell 窗口即可。

**窗口一：启动数据库只读接口**

```powershell
cd D:\DCMA-Agent\dashboard
npm run dev:database
```

**窗口二：启动前端页面**

```powershell
cd D:\DCMA-Agent\dashboard
npm run dev:frontend
```

在普通浏览器打开 [设备概览](http://127.0.0.1:3000/#overview)。两个窗口需要保持运行；分别按 `Ctrl+C` 可以停止。关闭窗口或重启电脑后，再执行以上命令。服务已运行时直接打开链接，不必重复启动。

| 服务 | 地址 |
|---|---|
| 前端页面 | http://127.0.0.1:3000 |
| 后端接口 | http://127.0.0.1:3001 |

两个服务只监听本机。`127.0.0.1` 指打开浏览器的这台电脑，其他电脑不能直接通过这个地址访问本机展板。

## 新电脑：首次准备

### 1. 环境要求

- Node.js 22.18.0或更新版本，以及随附的 npm。
- Git，用于克隆个人仓库。
- 能访问数据库的校园网或对应 VPN。
- 数据库连接账号和密码；这些配置不包含在 Git 仓库中。

启动展板无需运行 Pi SDK、登录模型或配置 OpenAI API Key。

### 2. 获取项目与安装依赖

以下以 Windows 的 `D:\DCMA-Agent` 为项目位置；如果保存到其他目录，调整后续 `cd` 路径。已有项目时跳过克隆步骤。

```powershell
git clone https://github.com/Xixi051108/DCMA-AGENT-PRIVATE.git D:\DCMA-Agent
cd D:\DCMA-Agent\dashboard
npm ci --ignore-scripts
```

个人仓库需要有访问权限。依赖安装在 `dashboard` 下统一进行，不需要分别在前后端安装。

### 3. 配置数据库

在 `D:\DCMA-Agent\dashboard` 中执行下面的命令，只在配置文件不存在时复制示例：

```powershell
if (-not (Test-Path database/.env)) {
    Copy-Item database/.env.example database/.env
}
```

编辑 `dashboard/database/.env`，核对以下配置：

| 配置项 | 用途 |
|---|---|
| `MYSQL_HOST` | 数据库主机 |
| `MYSQL_PORT` | 数据库端口，默认3306 |
| `MYSQL_USER` | 连接账号 |
| `MYSQL_PASSWORD` | 连接密码 |
| `MYSQL_DATABASE` | 展板使用的数据库，当前为 `dcma` |

修改配置后重启后端。保留已有配置，不将账号密码放进前端或提交到 Git；`.env` 已被忽略。

### 4. 启动

按上面的“已有本机环境”步骤分别启动前后端，然后打开页面。

## 数据来源与设备对应

正式页面读取数据库已有记录，不自动使用开发样例填充。

| 查看设备 | 来源 | 数据表 |
|---|---|---|
| G120电机1 | 模拟数据 | `real_data_01` |
| G120电机1 | 历史真实采集 | `real_data` |
| G120电机2 | 模拟数据 | `real_data_02` |
| G120电机3 | 模拟数据 | `real_data_03` |
| G120电机4 | 模拟数据 | `real_data_04` |

电机1可以切换两种来源；电机2～4的数据来源固定为各自的模拟表。模拟数据也是已入库的采样记录。

“实时数据”页定时读取数据库；数据库持续新增采样时，页面才会出现新记录。历史真实采集没有更新时显示“本次无新采样”，不代表数据库连接失败。

## 主要显示规则

### 时间、数值与字段

- 采集时间、入库时间、查询时间分别展示，处理后的时间统一显示为北京时间；原始时间字段保留原值。
- 页面字段名称使用中文，单位按已确认参考资料标注，不进行数值换算。
- 页面展示29个字段，已隐藏状态码和系统运行时间；数据库与接口仍保留31个原始字段。
- 有效0和负数保留，缺失显示“—”；趋势在缺失处断线，不补0。
- 卡片和仪表读数最多显示4位小数，完整参数与采样明细保留原值。
- 同一选择查询失败时保留上次成功结果并提示；切换设备时清空旧结果，取消旧请求，避免混入上一设备的数据。

### 六个仪表

| 指标 | 单位 | 显示范围 |
|---|---|---|
| 实际转速 | rpm | −1500～1500 |
| 实际电流 | A | 0～3.3 |
| 实际转矩 | N·m | 当前有效采样范围；恒定值时扩展显示跨度 |
| 直流母线电压 | V | 0～1200 |
| 变频器温度 | °C | 0～150 |
| 电机温度 | °C | 0～150 |

五项固定量程来自参考图，实际转矩按用户确认保留原采样范围。超量程时指针停在边界，数字仍保留实际值。量程是显示范围，不是已确认的设备安全阈值。

### 故障与报警

非零故障码显示红色，非零报警码显示深黄色，代码文字保持原值。0只显示0，不附加“正常”；缺失显示“—”。

历史异常使用所选来源的全部有效历史采样生成，不受50/100/200条近期采样窗口限制：

- 同一字段连续出现同一个非零代码，合并为一次事件。
- 首次观察到非零代码作为开始；观察到归零或换码时结束旧事件。
- 没有观察到结束时保留“未结束”，持续时间只计算已观察到的跨度。
- 缺失代码不会作为恢复；开始前缺少可确认记录时标记“最早观察时间”。
- 时间查询匹配与区间重叠的事件，保留原有完整起止时间，每页50条。
- 汇总和代码分布统计整个筛选结果的事件次数；下方代码采样表展示近期记录，可单独按类型、代码筛选。

事件起止时间受采样间隔限制，历史记录依赖数据库原始采样保留，没有单独创建永久事件表。原来重叠的“历史异常时段”图已删除，起止时间和持续时间保留在事件表中。

## 常见问题

| 问题 | 处理方式 |
|---|---|
| 浏览器打不开3000端口 | 确认前端终端仍在运行，检查是否已经关闭或启动失败 |
| 页面能打开，但显示接口查询失败 | 检查后端终端、数据库配置和校园网/VPN连接 |
| 提示端口被占用 | 确认是否已有展板服务运行；若已运行，直接打开页面，不重复启动 |
| 历史真实数据时间较早 | 这是数据库中的历史采集时间；查询时间更新不代表采集记录更新 |
| 指定时间段查不到异常 | 核对设备、来源和数据库实际记录日期，也可以点击“全部时间” |
| 电机2～4不能选历史真实采集 | 当前已确认的历史真实来源只属于电机1 |
| 重启电脑后页面打不开 | 重新运行前后端两个启动命令 |

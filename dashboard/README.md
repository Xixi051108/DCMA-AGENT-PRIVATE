# DCMA 电机监控展板

独立项目位于个人仓库 `Xixi051108/DCMA-AGENT-PRIVATE` 的 `main`。前端为 React / TypeScript / Vite / Tailwind，后端为 Node / MySQL，只查询 `dcma` 库的五张已确认表。无需启动 Pi SDK。

页面采用深蓝侧边栏、青色选中态与浅色数据面板，六个菜单均只显示“查看设备”选中的一台电机。正式页面只显示接口查询结果，不会以开发样例替代数据库。

## 启动

当前本机环境和 `database/.env` 已准备完成，在两个终端分别运行：

```powershell
cd D:\DCMA-Agent\dashboard
npm run dev:database
```

```powershell
cd D:\DCMA-Agent\dashboard
npm run dev:frontend
```

打开 <http://127.0.0.1:3000>。前端将 `/api/database` 转发到本机 `3001` 的后端，两个服务仅监听本机；分别按 Ctrl+C 停止。

新电脑需要 Node.js 22.18 或更新版本，在 `dashboard` 运行 `npm ci --ignore-scripts`。只有本机配置不存在时才复制示例：

```powershell
if (-not (Test-Path database/.env)) { Copy-Item database/.env.example database/.env }
```

编辑 `database/.env` 填写数据库账号密码，库名为 `dcma`，主机和端口已在示例中填写。需要校园网/VPN能够访问数据库。修改配置后重启后端；不要覆盖已有 `.env`，不要将凭据放进前端、截图或 Git。

## 页面操作与数据规则

- 侧边栏菜单：设备概览（运行快照与29字段完整参数）、实时数据（趋势与六个仪表）、运行指标（18项数值按运动、电气、功率、温度、负荷分组）、故障与报警（当前代码、全历史事件、时间范围查询、汇总、分布与代码采样记录）、采样明细（29字段原始记录，默认展开）、数据说明（当前来源、时间和读数规则）。默认打开实时数据；菜单支持地址片段与浏览器后退，切页回到顶部，保留设备、来源和采样条数选择。运行指标中的“查看趋势”跳转到对应曲线。
- 选择“查看设备”后，全页只显示对应电机的数据，不同时展示其他电机概览或来源警告。电机 1 默认模拟数据，可改为历史真实采集；电机 2～4仅有模拟数据，来源栏显示“模拟数据”并禁用切换。返回电机 1 时保留它此前的来源选择。
- 设备概览的“完整参数”按设备信息、采样信息、运动、电气、功率、温度、负荷参数、故障与控制分成8组，保留全部29项原值；桌面双列分区、窄屏单列，标题下不再显示字段数量说明。
- 故障与报警页的历史事件独立读取所选电机、来源的全部数据库采样，不受50/100/200条窗口限制，刷新后可重新生成，前提是原始历史仍保留。连续同码合为一次事件，首次观察非零为开始，首次观察归零或换码为结束；缺失代码不会作为恢复，故障和报警独立计算。最早历史记录已经异常时标记“最早观察时间”；未观察到结束时保留“未结束”，只显示已观察跨度，不使用当前墙钟推算。实际发生/恢复时刻受采样间隔限制。按北京时间选择起止范围，匹配所有与范围重叠的事件，保留完整起止时间；支持全部时间、每页50条、历史汇总与代码事件分布；分布独占一行，已移除重叠的历史异常时段图，起止时间与持续时间保留在历史记录表中。历史每30秒检查，或点击“查询异常”。下方代码采样表仍使用最近窗口，可按类型和代码文字筛选、重置；设备/变频器列与原始代码保留。切设备或来源清空旧历史及筛选，不混设备。
- 非零故障码显示红色，非零报警码显示深黄色；零值只显示0，和缺失值保持默认颜色。运行卡片、完整参数、代码记录与采样明细使用相同规则，代码文字保持原值。
- 监控页已移除卡片、分组、图表与表格的辅助说明和页脚规则提示，单位放在字段名称后。查询状态、采样条数、截断、错误与空数据提示仍显示；集中参考内容保留在“数据说明”页。
- 设备概览加入电机与变频器插图，数据说明页加入采样与记录插图；两幅本地SVG沿用蓝青配色，适配窄屏，仅作装饰，不表示实际设备外观或实时状态。
- 趋势默认设定/实际转速对比，可切换转矩对比或全部 18 个数值字段单项查看。采样条数为 50 / 100 / 200，默认 100。时间升序；缺失点断线，不补 0。
- 悬停查看北京时间、毫秒、记录编号和各曲线值；Tab 聚焦图表后用左右箭头查看相邻采样，Home / End 到首尾，Esc 关闭提示。采样明细支持 Enter 展开。
- 打开和切设备、来源、采样条数立即请求。每 5 秒自动检查，查询未结束时跳过，手动刷新查询期间禁用。切换取消旧请求并拒绝旧响应回写。
- 同一选择刷新失败保留上次成功结果并提示；首次或切换失败不展示其他设备的旧值。空表、无效时间、截断均有提示。
- 仪表按用户参考图固定五项左右极值：实际转速−1500～1500 rpm、实际电流0～3.3 A、直流母线电压0～1200 V、变频器/电机温度均0～150 °C；刻度不再随采样窗口变化。用户确认实际转矩仍保留原有N·m采样范围，恒定值扩展为非零跨度；不改为参考图中的转矩利用率百分比。超量程时仅指针停在边界，数字保留实际读数，缺失显示“—”且不画指针；固定刻度仍显示。显示量程不代表安全阈值。
- 单位参考用户截图：转速 rpm、电流 A、转矩 N·m、电压 V、功率 kW、温度 °C、负荷率 %，同类字段统一标注，不进行数值换算；脉冲频率单位待确认。卡片读数最多显示4位小数，参数和明细保留原值，有效0、负值及 `air_intake_temp=-200` 保留。`status` 和 `system_run_time` 在页面各处隐藏，数据库与接口仍保留31个原始字段，页面展示其余29个字段；字段名称仅显示中文及单位。故障码、报警码的零值仅显示“0”，不附加“正常”文字，非零保留原始代码，缺失显示“—”，控制字/状态字不解释。
- 采集时间、入库时间、接口查询时间分别显示；日期文本暂按北京时间解释，13 位时间戳按毫秒解析。无效采集时间不进入曲线，不用入库时间替代。
- 接口连接、数据来源和采集更新状态分别展示。“检测到新采样”来自相邻成功查询的记录变化；“本次无新采样”不等于连接失败。当前真实表为 2026-01-14 的历史采集。

## 只读接口

| 接口 | 用途与限制 |
|---|---|
| `GET /api/database/dashboard?table=real_data_01&limit=100` | 五个来源摘要、所选最新值、近期采样、原始记录和查询时间；limit仅支持50/100/200，响应上限512000字节，过大时明确截断较早记录 |
| `GET /api/database/code-history?table=real_data_01&page=1&from=2026-10-08T00:00:00.000Z&to=2026-10-10T00:00:00.000Z` | 所选来源全部历史生成的故障/报警事件；from/to可省略，使用标准ISO UTC时间；事件重叠筛选，50条/页及筛选结果汇总，page支持1～1000 |
| `GET /api/database/catalog` | 配置与连接状态、已知表的字段结构；`?refresh=1`重新检查 |
| `GET /api/database/rows?schema=dcma&table=real_data_01&limit=20` | 旧原始预览接口保留，1～200行/64KB；不作为趋势数据接口 |

`real_data_01`～`04`对应电机1～4的模拟表，`real_data`对应电机1历史真实采集。展板固定只读 `dcma`，不接受任意SQL或写入。原展板使用5秒SQL超时、15秒请求时限和18秒浏览器超时；历史接口以只读事务流式遍历所选来源的采集时间、编号和代码，不把全部采样放进响应，SQL55秒/请求60秒/浏览器65秒超时，支持取消。两类查询均保留参数绑定。发现一个来源有多个设备/变频器时停止混合展示；无设备标识记录被排除。
